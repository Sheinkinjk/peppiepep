# Expansion: the discount-code programs worth pursuing next

**Prepared 26 September 2026, for Jarred.** Research only; nothing on the site changed. Builds on the September sweeps in this folder (`code-culture-map`, `volume-sweep-B1/B2`, `expansion-decision-v2`) and adds the categories they never covered: other telehealth lines, sleep equipment, longevity programs, broadband, lead marketplaces. Every payout below is either quoted from the program's own listing with the URL, carried over from a sweep that did the same, or marked **UNVERIFIED**. Where a figure is unverified, the next step is the email that settles it, not a guess.

## What the current business says a good program looks like

Two-and-a-bit transactions a day, about A$600, come from three codes. Every one of them shares four properties, and every property below is a screen:

1. **The purchase has an assessment step and a high value to the merchant.** Telehealth pays A$200 to A$300 because the merchant is buying an assessed patient, not a click.
2. **The code is unique to Refer Labs and credited on redemption**, so a customer who saw the code anywhere, including an AI answer, pays us when they type it. `no-click-mechanism-2026-10.md`: 57% to 97% of transactions never visit the site.
3. **The terms do not exclude coupon or comparison traffic.** Hims' partner terms bar exactly that without an Approved Channel; Booking.com and Expedia zero-rate coupon orders. A program that fails this pays A$0 by the route that earns.
4. **The brand has, or will have, search demand.** `brand-search-demand`: Mosh 6,500 impressions in 90 days, Moshy 2,367, Juniper 1,632, then a cliff. A code for a brand nobody searches is a code nobody types.

The honest arithmetic before the list: ten streams does not mean ten times revenue. It means ten chances at a Moshy, and most will run at a fraction of Moshy because the brand demand is smaller. The list is ordered by how many of the four properties each program has **today**, with certainty stated.

## The finding that reorders the list

**Hims now owns Juniper, Pilot, Kin and Software.** The acquisition closed on 2 June 2026. The Approved Channel decision you are already waiting on is not one brand; it is potentially four telehealth lines under one agreement, one disclosure statement and one code policy. That makes the Hims email the highest-value single action on this list by a wide margin, and it makes the concentration risk in the growth plan sharper: with Mosh and Moshy as one company and Hims as the other, a fifth and sixth brand from the same two parents does not diversify anything. **Youly, CPAP Organisation Australia and Everlab are on this list partly because they are not owned by either.**

## On broadband

Three programs (Exetel A$80 with clickless tracking, Superloop to A$70, Aussie Broadband to A$75) with published rates and codes, in a category the site has never touched: zero impressions, no hub, no pages. It would be a new section built from scratch, against Finder, WhistleOut and Canstar Blue, who own every generic broadband query. The only version worth building is the one the citation rule allows: a single page that owns a fact the incumbents get wrong (a dated, verified table of what each provider actually charges after the promotional period ends, for example), carrying the three codes. Not a hub, not a guide cluster. If that page cannot rank inside a quarter, the section is closed.

## Next steps, in order

The order is by expected value per hour, and the first five are emails.

1. **Hims (this week).** Approved Channel for referlabs.com.au in writing; the Disclosure Statement wording; and whether Kin and Software are in scope. One email, three questions, potentially four brands.
2. **CPAP Organisation Australia (this week).** Register on the UpPromote link, request the branded coupon, and confirm the 11% applies to machines. Then one dated page under `/sleep` stating machine prices from their own store, with the code, and the existing sleep-apnoea guides linking to it. This is the only item on the list that can be live inside a fortnight with a verified payout and a verified code.
3. **Youly (this week).** A partnership proposal, not a code request: what the site is, where the code would sit (a women's-health page that does not exist yet), and the ask for a code credited on redemption with monthly redemptions reported. Their page says explicitly that code-only requests are ignored.
4. **Everlab (this week).** Apply as a publisher. The site already ranks for their brand; that is the pitch.
5. **EcoFlow (this week).** Ask for a Refer Labs code. The page exists, the network supports it, and it costs one email.
6. **Carbar and Carly (before any page).** A compliance opinion on whether car subscription is consumer credit under the NCCP. If it is, the category is closed; if not, two A$100-a-lead programs with codes.
7. **Solar Choice, Why Solar, Your Solar Quotes (in parallel).** Apply to all three; the rates arrive on approval. Whichever pays best becomes the second buyer behind Apollo for the battery leads the site already captures.
8. **Broadband: decide, do not drift.** Either commission the one owned-fact page described above with a quarter's kill gate, or leave the category alone. Three verified programs are not a reason to build a section the site cannot rank.
9. **Laser Clinics, Lekker, Star RV, CircleDNA.** Apply where it is free to apply; build nothing until a code and a rate are in hand and a page passes the revenue-first rule in CLAUDE.md.

What not to do: build any page before the code exists. Every entry on this list that would need a new page (Youly, Kin, Software, CPAP, broadband) is a page that earns nothing until the code is issued, and a code that is issued can go onto an existing page the same day.

**Kill gate for the whole exercise, 31 December 2026:** if fewer than three new redemption-credited codes are live by then, the constraint is partner supply, not research, and the effort moves to rank on the codes already held.
