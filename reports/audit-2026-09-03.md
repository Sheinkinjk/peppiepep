## 2. Crawler access verdict

**AI crawlers can reach the site, and are served exactly what a browser is
served.** Six agents (GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, CCBot,
plain curl) were fetched against 7 routes including `/moshy`, `/moshhair`,
`/deals` and `/knose`. Every response was **HTTP 200 with 0.0% size drift** from
the browser response. There is no middleware bot-gating, no geo-gating, no rate
limiting, no Vercel deployment or password protection, and no `X-Robots-Tag`
header on any tested route. `next.config.ts:325` sets only `Cache-Control`.
`vercel.json` contains no headers or protection. `src/proxy.ts` emits
`x-robots-tag: noindex` only on the 410 `GONE` list.

Per-agent robots.txt verdict:

| agent | verdict |
|---|---|
| GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, Perplexity-User, ClaudeBot, anthropic-ai, Amazonbot, meta-externalagent | explicitly allowed, own group |
| Google-Extended, Applebot-Extended | explicitly allowed, own group (training controls, **not ranked as retrieval causes**) |
| Claude-User, CCBot, Bytespider | not named; fall under `User-agent: *`, which is `Allow: /` |

**This explanation is ruled out.** Verbatim robots.txt is in
`reports/raw/crawler-access.json`.

## 6. Open questions for a human

1. **Does any partner agreement restrict publishing discount codes?** `/juniper`
   carries a verbatim-mandated disclosure and a medication-language prohibition
   from Juniper's handbook (`src/app/juniper/page.tsx:191`,
   `src/components/consumer/PathwayQuiz.tsx:114`). No copy of that handbook is in
   the repo. If it restricts code publication, part of the coupon-query gap is
   contractual, not technical.
2. **Is a code that appears on no public merchant page indexable at all?**
   `src/lib/offers.ts` records six codes as `noPublicPage` — partner-specific,
   stated nowhere a crawler can corroborate. An engine that cross-checks a code
   against the merchant's own site finds nothing. This is a commercial question
   about which codes we hold, not a code change.
3. **Should the four undated hub routes carry a date, or should they stop naming
   codes?** `/`, `/guides`, `/hair-loss`, `/weight-loss` are hubs, not offer
   pages.
4. **`reviewedBy` is unpopulated everywhere.** Whether to populate it is an
   editorial-staffing question, not a technical one.
